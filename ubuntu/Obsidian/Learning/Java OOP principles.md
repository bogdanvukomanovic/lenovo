- Abstraction and hierarchical abstraction/classification

1. **Encapsulation** is the mechanism that binds together code and the data it manipulates, and keeps both safe from outside interference and misuse. 
2. **Inheritance** is the process by which one object acquires the properties of another object. 
3. **Polymorphism** is a feature that allows one interface to be used for a general class of actions. The specific actions is determined by the exact nature of the situation. The concept of polymorphism is often expressed as "one interface, multiple implementations". The same interface can be used to control a number of different implementations.
